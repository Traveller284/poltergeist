# Kiro usage log

Keep this updated as you build. It becomes the "how Kiro was used" write-up that judges score. Write what actually happened, including what went wrong. Judges reward real experimentation.

## Surfaces (IDE, CLI, Web, Crew)
- Which did you try? How did they differ?

## Spec-driven development
- How did you structure the specs? What did vibe coding do better or worse?

## Steering
- Which steering file changed Kiro's output the most? Example before and after.

## Hooks
- What did each hook automate? What did it cost in credits?

## Custom agents
- Which agents, in which Kiro app, and what changed?

## MCP and powers
- What did you connect or install, and what would have been hard without it?

## Property-based testing
- Bugs that PBT caught which unit tests missed. Paste the shrunk counterexample.

## Credits
- Rough credit use per phase.
